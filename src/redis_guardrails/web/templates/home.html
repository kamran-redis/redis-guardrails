How a check works

A message goes in, gets embedded and compared against every guardrail's examples by vector distance, and the closest match under its threshold decides the verdict.

  1. 01
    Text
    The user's message, or the model's reply.
  2. Chunk & embed
    Split into chunks and embedded as vectors.
  3. Vector similarity search
    Checked against every guardrail's examples by distance.
  4. Allow, flag, or block
    Closest match under threshold wins.

What's a guardrail

A guardrail is one rule: a scope, a category, a few example phrases, an action, and a threshold. There's one per behavior you want to catch — not one giant policy.

BLOCK gr-unverified-transfer-002
scopeinput
categoryunverified_transfer
example phrase"...skip verification"
match threshold0.40

Scope — input or output. Scopes are just strings, so new ones can be added as needed.

Category — the label shown on results and benchmark reports.

Examples — reference phrases the incoming text is measured against by vector distance, not exact strings.

Threshold — max distance still counted as a match. Lower = stricter, catches only close paraphrases.

Action is the verdict this rule hands back when it fires — ALLOW, FLAG, or BLOCK — shown here as the badge on the rule's ID.
